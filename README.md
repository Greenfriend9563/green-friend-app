## ⬇️ অ্যাপ ডাউনলোড

সর্বশেষ ভার্সন পেতে **[Releases](../../releases/latest)** পেজে যান এবং `Green-Friend.apk` ফাইলটা ডাউনলোড করুন।

সরাসরি লিংক:
```
https://github.com/Greenfriend9563/green-friend-app/releases/latest/download/Green-Friend.apk
```

## 📲 ইনস্টল করার নিয়ম

1. উপরের লিংক থেকে `Green-Friend.apk` ডাউনলোড করুন
2. ডাউনলোড শেষে ফাইলটা খুলুন
3. Android বলবে — *"For your security, your phone is not allowed to install unknown apps from this source"*
   → **Settings** চাপুন → **Allow from this source** চালু করুন
4. ফিরে এসে **Install** চাপুন
5. ইনস্টল শেষে **Open** চাপুন — ব্যস!
